# 🚦 Traffic Karma

Traffic Karma is a traffic management simulation game developed using **Unity** and **C#**. Players must manage vehicle movement, prevent accidents, and maintain smooth traffic flow while handling increasing traffic density. The game focuses on strategic decision-making, quick reactions, and efficient traffic control to achieve the highest possible score.

## 🎮 Gameplay

The objective of the game is to keep traffic moving efficiently by controlling vehicles and avoiding collisions. As the game progresses, traffic becomes more challenging to manage, requiring players to make faster and smarter decisions to maintain order on the roads.

## ✨ Features

- 🚗 Realistic vehicle movement and traffic simulation.
- 🚦 Interactive traffic control mechanics to manage traffic flow.
- 💥 Collision detection system for identifying and handling accidents.
- 🏆 Score-based progression system to reward efficient traffic management.
- 📈 Increasing difficulty to provide a challenging gameplay experience.
- 🎨 Simple and intuitive user interface.

## 🚀 Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/Traffic-Karma.git
```

2. Open the project in Unity.
3. Load the main scene.
4. Press **Play** in the Unity Editor.

## 🎯 Controls

| Action | Control |
|----------|---------|
| Select Vehicle | Mouse Click |
| Control Traffic | Mouse Click / Tap |
| Pause Game | Esc |
